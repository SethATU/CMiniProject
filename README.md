# C Programming Tic Tac Toe Project 

The project was to create a working Tic Tac Toe game in the C programming laungauge.

The project was worked on by both contributors, developing a working game in both C and C++. A user can play a competitive game of Tic Tac Toe against a bot, The game will keep track of the user and bot inputs and can reset the board and keep score of how many games where won, lost or drawn.
